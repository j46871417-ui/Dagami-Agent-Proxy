# Быстрый старт — Dagami Agent Proxy 0.5.0 beta

## Windows: подключение за несколько шагов

1. Скачайте `Dagami-Agent-Proxy-v0.5.0-beta-windows.zip` из
   [релизов](https://github.com/j46871417-ui/Dagami-Agent-Proxy/releases/tag/v0.5.0-beta).
   Распакуйте в постоянную папку и запустите `DagamiAgentProxy.exe`.
2. Получите ключ командой `/key` в [@bright26bot](https://t.me/bright26bot).
   Вставьте его в окно активации. Адрес шлюза определяется автоматически.
   Если программа уже открыта: **Подключение → Подключить по ключу**.
3. Полностью закройте приложение, которое собираетесь использовать, включая
   его фоновые процессы. В разделе **Приложения** выберите его и нажмите
   **Запустить через Dagami**. Если его нет в списке, используйте **Добавить**.
4. Проверьте вход и отправьте запрос к модели в самом приложении.
5. Чтобы пользоваться привычным ярлыком или командой CLI, выберите приложение
   и нажмите **Действия → Настроить обычный запуск**. После изменения PATH
   откройте новый терминал.

Оставляйте Dagami работающим, пока используете запущенные через него приложения.
Выбранное подключение общее для совместимых приложений, запущенных через Dagami
или настроенный запуск. Для WSL, SSH и контейнеров сеть настраивается отдельно.

## Если у вас свой прокси или VPN

В Windows откройте **Подключение**, введите HTTP/HTTPS-прокси, например
`http://127.0.0.1:7897`, и нажмите **Использовать свой прокси**. Для системного
VPN укажите `direct`. Порт должен совпадать с HTTP-входом вашего VPN-клиента.
Первичная активация Windows-клиента и выбор своего прокси — отдельные операции.

## macOS и Linux

Скачайте пакет для своей архитектуры. Откройте приложение, затем
**Подключение → Dagami через бота**, вставьте ключ из `/key` и нажмите
**Активировать**. Для своего подключения используйте **Свой прокси**,
сохраните профиль, выделите его и нажмите **Выбрать**.

Если связь не работает, откройте **Диагностика** в Windows или
**Подключение → Проверить связь** в macOS/Linux. Системный DNS для обычного
подключения по ключу менять не требуется.
