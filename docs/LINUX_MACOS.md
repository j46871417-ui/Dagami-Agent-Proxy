# Dagami Agent Proxy для Linux и macOS

Ключ из `/key` используется только для прокси Dagami. Для запуска приложения,
своего HTTP-, HTTPS- или SOCKS-прокси и прямого подключения ключ не требуется.

| Система | Пакет | Запуск |
| --- | --- | --- |
| Linux x64 или ARM64 | `Dagami-Portable-linux-amd64.zip` или `Dagami-Portable-linux-arm64.zip` | Распакуйте и запустите `./DagamiAgentProxy`. Для окна нужен GTK 3, для сохранения реквизитов нужен Secret Service и `secret-tool`. |
| macOS 13+, Apple Silicon | `Dagami-Portable-darwin-arm64.zip` | Распакуйте и откройте `Dagami Agent Proxy.app`. |
| macOS 13+, Intel | `Dagami-Portable-darwin-amd64.zip` | Распакуйте и откройте `Dagami Agent Proxy.app`. |

Сборки macOS не имеют Developer ID и нотарификации. Пароли и ключ устройства хранятся в Keychain или Secret Service. Формат настроек Go-клиента сохранён. Профили отдельного Python/Swift-форка добавляются вручную.

## Запуск IDE

1. Выберите профиль на странице **Подключение**.
2. Закройте уже запущенную копию IDE. В списке **Приложения** выберите её и нажмите **Запустить через Dagami**.
3. Для последующих запусков из меню приложений или Finder нажмите **Пропатчить**. Linux добавит `.desktop` в `~/.local/share/applications`. macOS создаст `.app` в `~/Applications/Dagami Launchers`. Выберите этот новый ярлык для запуска через Dagami.
4. Чтобы убрать отдельный ярлык, нажмите **Отменить патч**. При вручную изменённом файле Dagami сохранит его и сообщит о конфликте.

Подготовка создаёт отдельный запуск и не меняет бинарники, системные ярлыки IDE или вход в аккаунт. CLI запускаются в терминале через `./DagamiAgentProxy run APP_ID -- ARGS`. На macOS файл CLI находится в `Dagami Agent Proxy.app/Contents/MacOS/DagamiAgentProxy`.

Прокси применяется в дочернем процессе и, для совместимых приложений, через параметры Chromium. Оставляйте Dagami открытым, пока IDE использует локальный мост. Если мост закрыт, запустите IDE заново с нужным профилем. При прямом подключении дочернее приложение использует обычную сеть и окружение.

## Восстановление

Нажмите **Восстановление** в окне Dagami или запустите `DagamiRecovery` в Linux и `Dagami Recovery.app` на macOS. Команда `./DagamiAgentProxy --recover` выводит отчёт без GUI. Помощник отменяет собственные управляемые запуски, восстанавливает подтверждённые DNS-изменения из журнала и выбирает прямой маршрут. Сохранённые профили и реквизиты остаются доступными. Перезапустите открытые IDE, чтобы они заново прочитали сетевые настройки.

Ручная настройка DNS использует `networksetup` на macOS и `resolvectl` с `pkexec` в Linux. Для неё нужны права ОС. При конфликте журнал сохраняется. Для удаления переносимого пакета сначала выполните восстановление, затем удалите распакованные файлы или `.app`.
