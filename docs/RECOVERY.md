# Восстановление интернета и удаление

Приложение не требует лицензии. Ключ из `/key` нужен только для прокси Dagami.
Откат работает без сервера, ключа и установленного WinDivert.

## Если после Dagami пропал доступ к сети

1. На главной странице нажмите **Восстановить интернет**. Если окно не открывается,
   запустите **DagamiRecovery.exe** из распакованного пакета.
2. Нажмите **Восстановить обычный интернет**, прочитайте отчёт.
3. Перезапустите браузер/IDE: запущенный процесс хранит унаследованные переменные
   до своего завершения. Ваши приложения не закрываются принудительно.

Помощник снимает только принадлежащий Dagami PAC, возвращает сохранённые переменные
прокси, настройки приложений, ярлыки, команды CLI и собственные правила DNS.
Для системного DNS Windows может запросить UAC. Произвольного сброса всей сети нет.
При конфликте или повреждённой копии он сообщает проблему и сохраняет журнал.
Восстановление не может восстановить физически удалённые пользователем резервные копии.

Если требуется только одно приложение, используйте **Отменить патч** в его карточке.
Для временного отключения расширения браузера выключите его переключатель.

## Удаление

Откройте **DagamiUninstall.exe** или пункт **Удалить Dagami** в трее.
Сначала выполняется восстановление. При любой ошибке автоматическое удаление
не начинается. Собственная DNS-служба удаляется только после проверки владельца
и отсутствия ссылок адаптеров/NRPT на локальный DNS; это может потребовать UAC.

После успешного восстановления помощник удаляет только три одноимённых EXE
этого пакета из одной папки, проверяя их SHA-256. Посторонние файлы не удаляются.
Защищённые настройки, история восстановления и копия бывшей DNS-службы сохраняются.
Расширение удаляется отдельно в браузере: приложение не управляет профилем браузера.
Если папка защищена от записи или компонент отличается, удалите пакет вручную
после успешного отчёта восстановления.

## CLI

`DagamiAgentProxy.exe --recover` и `--uninstall` открывают те же помощники.
`--recover --dry-run` выводит план без изменения сети.
Существующие `dns restore` и `unpatch` также не требуют ключа приложения.

## Расширение

Версия 0.3 проверяет маршрут через мост, а не только открытый локальный порт.
Если проверка не проходит, фоновый монитор возвращает обычные настройки браузера
и сохраняет причину в окне расширения. Проверка запускается раз в 30 секунд;
задержки фоновых задач браузера могут увеличить интервал. Для возобновления
восстановите подключение в Dagami и включите расширение снова.
Это проверка транспорта userinfo, а не гарантия ответа каждой модели или региона.
