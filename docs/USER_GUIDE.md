## Что делает Dagami

Dagami запускает совместимые IDE и CLI через выбранное подключение. Это может
быть управляемый маршрут Dagami, ваш HTTP/HTTPS-прокси или системный маршрут
с уже работающим VPN. Переносимый клиент также поддерживает SOCKS5.

Приложения получают настройки локального прокси-моста. Поэтому Dagami должен
работать во время таких сессий. Обычный запуск можно настроить отдельно в Windows.
Произвольный процесс, запущенный вне Dagami без такой настройки, автоматически
в его маршрут не попадает.

Удалённые среды SSH, WSL, контейнеры и расширения со своим сетевым стеком могут
использовать отдельное подключение. Доступность модели также зависит от аккаунта,
подписки, квот и правил самого сервиса.

в постоянную папку до настройки ярлыков: они должны находить её по тому же пути.

## Подключение по ключу Telegram

### Windows

1. Получите свежий ключ командой `/key` в [@bright26bot](https://t.me/bright26bot).
2. При первом запуске вставьте его в окно активации. В открытой программе
   используйте **Подключение → Подключить по ключу**.
3. Дождитесь подтверждения. Программа сама получает адрес шлюза и выбирает
   маршрут Dagami.
4. При необходимости нажмите **Проверить привязку**. Привязка устройства
   и успешный ответ модели проверяются отдельно.

### macOS и Linux

Откройте **Подключение → Dagami через бота**, вставьте ключ и нажмите
**Активировать**. Маршрут Dagami включится после успешной привязки.
Ссылка **Получить ключ** открывает бота. Привязка по ссылке оставлена
как дополнительный способ подключения.

Ключ доступа имеет ограниченный срок действия. Если он истёк, запросите новый.
Вводите ключ целиком, сохраняя регистр. Не публикуйте его и не добавляйте
в скриншоты. При достижении лимита устройств отзовите старые устройства через
меню бота. Перенос настроек на другой компьютер может потребовать новой привязки.

Адрес шлюза и обычные реквизиты HTTP-прокси пользователю управляемого маршрута
вручную вводить не требуется. Подробности привязки: [доступ Dagami](../MANAGED_ACCESS.md).

## Свой прокси и системный VPN

### Windows

В разделе **Подключение** введите адрес в поле **Свой HTTP/HTTPS-прокси**
и нажмите **Использовать свой прокси**.

| Пример | Значение |
| --- | --- |
| `http://127.0.0.1:7897` | Локальный HTTP-прокси VPN-клиента |
| `proxy.example:8080` | HTTP-прокси без явного указания схемы |
| `http://user:password@proxy.example:8080` | Прокси с логином и паролем |
| `https://proxy.example:8443` | Прокси с TLS-соединением до самого прокси |
| `direct` | Системный маршрут, в том числе уже включённый VPN/TUN |

Адреса `proxy.example` приведены только как образцы. Спецсимволы логина
и пароля должны быть закодированы для URL, например `@` как `%40`.
Не добавляйте путь или параметры запроса к адресу прокси. Windows WinForms
не принимает SOCKS5 как собственный прокси: включите HTTP-вход своего клиента.
Номер порта берите из его настроек; одинаковый номер не означает одинаковый протокол.

Кнопка **Использовать Dagami** возвращает к сохранённой привязке. Свой адрес
хранится отдельно. Первичная активация Windows-клиента сохраняется и при выборе
своего подключения.

### macOS и Linux

В **Подключение → Свой прокси** задайте название и полный HTTP, HTTPS или SOCKS5
URL, затем нажмите **Сохранить**. Выделите профиль и нажмите **Выбрать**.
Для уже работающего VPN выберите профиль **Системный маршрут / VPN**.

При смене подключения сохраните работу и остановите активные сессии. Windows
запрашивает подтверждение перед их остановкой. После смены маршрута запускайте
приложения заново; существующие соединения сами на новый выход не переносятся.

## Запуск приложений

В **Приложения** выберите установленный клиент и нажмите **Запустить через
Dagami** в Windows или **Запустить** в macOS/Linux.
Перед этим полностью завершите старый экземпляр: новое окно может присоединиться
к уже работающему процессу с прежними настройками сети.

Если приложение не обнаружено, используйте **Добавить** и укажите исполняемый
файл. В macOS можно указать пакет `.app`; в переносимом интерфейсе путь также
меняется через **Изменить путь**. Добавление в список само по себе не меняет
файлы приложения. Возможности настройки зависят от его типа и версии.

В Windows для привычных ярлыков и CLI выберите **Действия → Настроить обычный
запуск**. После изменения PATH откройте новый терминал. Если приложение
обновилось или было перемещено, проверьте статус и повторите настройку.
Список известных клиентов и особенности: [поддержка приложений](../APPLICATIONS.md).

Для остановки используйте **Действия → Остановить** в Windows или **Остановить**
в переносимом клиенте. Остановка может закрыть фоновые процессы сессии:
предварительно сохраните файлы и незавершённые запросы.

## DNS и восстановление

Обычное подключение по ключу работает через шлюз и не требует включения
системного DNS. Раздел **DNS и сброс** нужен для отдельных сценариев.

В Windows доступны **Включить в Windows**, **Настроить DNS вручную…**
и **Очистить все DNS и NRPT…**. После включения кнопка меняется на
**Восстановить прежний DNS**. Системные операции используют резервную копию
и могут запросить UAC.

Полная очистка DNS/NRPT — отдельная операция восстановления. Сначала прочитайте
её подтверждения: она затрагивает системные правила, включая настройки,
которыми могут пользоваться VPN или рабочая сеть. Для обычного отключения
используйте восстановление прежнего DNS. [Подробности и откат](../SYSTEM_DNS.md).

В Windows выберите **Действия → Отменить патч (вернуть исходный запуск)**.
Отдельное восстановление ярлыков и параметров находится в **Действия →
Дополнительно**. Прочитайте подтверждение восстановления: ручные изменения управляемых
прокси-полей могут быть заменены исходными значениями. Выполняйте откат
до удаления Dagami и его резервных копий.

## Обновление

В Windows откройте **Обновления**, нажмите **Проверить**, затем
**Скачать и установить**, если найдена новая версия. Для beta-релизов включите
показ предварительных версий. Автоматическая проверка может уведомлять
о релизах, установка запускается пользователем.

Перед установкой сохраните работу и остановите управляемые сессии.
При ручной замене завершите Dagami через **Выход** в трее и распакуйте новый EXE
в прежнюю папку. Сохранение пути помогает сохранить работоспособность ярлыков.
В macOS/Linux скачайте подходящий новый пакет и замените приложение после выхода.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Не открывается Telegram | Откройте `@bright26bot` вручную, отправьте `/key` и вставьте результат в программу |
| Ключ не принимается | Получите свежий ключ; проверьте полноту, регистр, время на компьютере и лимит устройств |
| Не удалось связаться со шлюзом | Проверьте интернет, время компьютера, доступность службы и наличие новой версии. Приложите очищенный журнал; не подставляйте случайный IP вместо имени HTTPS-сервера |
| HTTP 407 | Проверьте логин/пароль собственного прокси или состояние привязки Dagami |
| HTTP 401/403, ошибка региона или подписки | Сервер мог ответить, но отказать аккаунту или маршруту. Проверьте вход, права, регион выхода и ответ в самом клиенте |
| HTTP 429 | Проверьте квоту сервиса и повторите запрос позже |
| Ошибка TLS/сертификата | Проверьте дату, имя сервера и доверие к сертификату; сохраните точный текст ошибки |
| Прокси включён, приложение идёт прежним маршрутом | Завершите старые процессы и запустите через Dagami; проверьте отдельную сеть WSL/SSH/контейнера |
| Локальный прокси не отвечает | Убедитесь, что VPN-клиент запущен, выбран нужный порт и его протокол соответствует введённому URL |

Проверка связи находится в **Диагностика** в Windows и
**Подключение → Проверить связь** в macOS/Linux. Ответ публичного адреса
подтверждает сетевой этап; вход и работу модели проверяйте отдельно.

В Windows откройте **Сообщить о сбое**. Опишите шаги, версию Dagami и приложения,
ожидаемый результат и ошибку. Просмотрите журнал и изображение перед отправкой:
автоматическая очистка распознаёт известные форматы секретов, но не любое
личное содержимое. В переносимом клиенте скопируйте нужные события из **Журнала**
и удалите секреты перед публикацией. [Как устроены отчёты](../BUG_REPORTS.md).

## Настройки и удаление

Windows WinForms использует `%APPDATA%\devproxy`; при проблемах с основным
расположением конфигурация может использовать `%LOCALAPPDATA%\devproxy`.
Защищённые ключи привязаны к пользователю ОС. Переносимый клиент использует
каталог `DagamiAgentProxy/native-v1` внутри системного каталога конфигурации
пользователя и DPAPI, Keychain или Secret Service для секретов.

Перед удалением восстановите настроенные запуски и системный DNS, остановите
сессии и выйдите из Dagami. При отказе от управляемого доступа отзовите устройства
в боте. Затем удалите файлы программы; настройки и резервные копии удаляйте
после проверки успешного отката. [Автозапуск Windows](../STARTUP.md).
