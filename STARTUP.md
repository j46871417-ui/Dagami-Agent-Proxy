# Запуск и права в Windows

В Windows нужен один `DagamiAgentProxy.exe`. В нём встроен запрос прав
администратора. При ручном запуске Windows покажет UAC до открытия
программы; при отказе программа не запустится. Если права уже выданы,
повторный запрос не нужен. CLI запускайте из терминала с правами
администратора.

## Автозапуск

1. Запустите и при необходимости активируйте программу вручную.
2. Откройте «Подключение» → «Постоянные настройки».
3. Отметьте «Запускать при входе в Windows — в трей, с правами администратора».

Изменение вступает в силу сразу, кнопка «Сохранить» для него не нужна.
Строка под галочкой покажет итог проверки. По умолчанию автозапуск выключен.

При входе в Windows планировщик запустит эту копию с повышенными правами
в текущем сеансе пользователя, с задержкой 10 секунд. Окно останется в
трее; открыть его можно двойным щелчком по значку. Пароль не сохраняется.
Повторный запуск задачи не создаёт вторую копию и не открывает окно
уже запущенного менеджера. Неактивная программа не показывает окно
активации при входе в систему; её нужно один раз открыть вручную.

Для отключения снимите ту же галочку. Удаляется только своя задача
`DagamiAgentProxy-Startup-<SID>`. Чужая или изменённая задача не будет
удалена или перезаписана; причина будет показана в окне.

Автозапуск хранит полный путь к EXE. Если вы переместили программу,
откройте новую копию и включите автозапуск для неё. Старые файлы и
другие задачи Windows эта настройка не удаляет.

В локальном порте Linux/macOS есть отдельный пользовательский автозапуск:
XDG Autostart либо LaunchAgent. GUI не получает root; права для DNS
запрашивает отдельный режим того же файла. [Порт и пределы проверки](PORTABLE.md).
