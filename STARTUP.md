# Запуск и автозапуск Windows

Windows GUI и CLI работают с обычными правами пользователя. Изменение системного
DNS запрашивает права отдельно. Встроенное обновление требует обычных прав и
доступной для записи папки установки.

## Автозапуск

1. Откройте и при необходимости активируйте Dagami.
2. Перейдите в «Подключение → Дополнительные настройки».
3. Отметьте «Запускать Dagami Agent Proxy вместе с Windows».

Строка под галочкой показывает результат. Изменение применяется сразу.
При входе в Windows планировщик запускает текущий EXE в трее с правами пользователя.
Пароль учётной записи не сохраняется. Повторный запуск задачи сохраняет один
экземпляр программы.

Окно открывается двойным щелчком по значку в трее. Неактивированную программу
следует сначала открыть вручную и ввести ключ.

Для отключения снимите ту же галочку. Удаляется задача
`DagamiAgentProxy-Startup-<SID>`. Чужая или изменённая задача требует ручного
разбора. Прежнюю управляемую задачу с повышенными правами приложение распознаёт
и заменяет при повторном включении автозапуска.

Автозапуск хранит полный путь к EXE. После переноса Dagami в другую папку
включите его заново из новой копии.

Пакеты macOS и Linux используют другой клиент. Его возможности и требования
описаны в [NATIVE_NEXT.md](NATIVE_NEXT.md).
