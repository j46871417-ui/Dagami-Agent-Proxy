## Системный DNS

Добавлено окно «Подключение → Системный DNS…» по механизму приложенных run_as_admin.bat / setup_smartdns_windows.ps1.
Модуль встроен ресурсом в EXE, отдельные файлы пользователю не нужны.

- DNS по умолчанию 185.149.145.6; выбор активных адаптеров и раздельное включение DNS/NRPT.
- 68 доменов исходного скрипта плюс два существующих API Antigravity; есть сокращённый набор без игр/стриминга.
- Конфликтующие правила не удаляются молча: замена — отдельной отметкой с резервной копией. Сложные DNSSEC/DirectAccess/IPsec и правила вне набора не переписываются.
- UAC вызывается только для применения/отката. Основной DevProxy и bridge не повышают права.
- Защищённое хранилище ProgramData/DevProxy-SystemDns: Administrators/SYSTEM write, Users read; GUID заданий и ограниченный JSON-запрос вместо произвольных путей/команд.
- Скрипт запускается системным PowerShell без профиля, с системным PSModulePath. Контроль целостности извлечённого ресурса; нет исполнения скриптов из пользовательских файлов.
- Снимки исходного DHCP/статики IPv4 и IPv6, статических DNS и заменяемых NRPT-правил. Индекс проверяется по GUID. При частичном сбое — автоматический откат; последующие внешние изменения не перезаписываются.
- Повторное применение не уничтожает исходную резервную копию. Ошибки и результат остаются в окне и журнале.
- Чтение адаптеров выполняется в фоне без зависания интерфейса.

Системные DNS/NRPT этим обновлением НЕ применялись. Хранилище состояния системного DNS не создавалось.
Пользователь применяет настройку своей явной кнопкой с UAC. Функция меняет DNS для всего компьютера и сохраняется после выхода из DevProxy; это отдельно от маршрута двух API в локальном bridge.
Реальное повышение через UAC и запись DNS на адаптеры в этой сессии не выполнялись; автоматические проверки использовали временные модели команд.
