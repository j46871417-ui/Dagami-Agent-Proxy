# Dagami Agent Proxy 0.3.0 альфа

Обновление после `v0.2.0-alpha`: совместимость с новой структурой Antigravity IDE,
обнаружение Codex Desktop, исправления по пользовательским логам и меньше
дублирующих действий в интерфейсе.

## Что изменилось

- **Antigravity IDE 2.6.** Распознаётся `Antigravity IDE.exe`, каталог плагина `agy`
  и общий `%LOCALAPPDATA%/agy/bin/agy.exe`. Manager и IDE могут быть в списке
  одновременно. Для IDE используется отдельный путь настроек.
- **Codex Desktop из Microsoft Store.** Приложение находится по регистрации
  пакета `OpenAI.Codex` и манифесту, даже если главный файл называется `ChatGPT.exe`.
  Обычный ChatGPT и консольный помощник не принимаются за Codex Desktop;
  заранее открывать программу для обнаружения не требуется.
- **Локальные запросы остаются на компьютере.** Исправлена передача ConnectRPC
  POST и CONNECT к локальному backend. CSRF, пользовательская авторизация, тело
  запроса и потоковые ответы сохраняются; пароль внешнего прокси туда не попадает.
  Адрес моста в `antigravity.serverUrl` больше не принимается за адрес backend.
- **Проверка прокси стала точнее.** Вместо одного TCP-порта проверяется CONNECT.
  Ответ 407 объясняется как отказ авторизации прокси, 403/503 — как отказ самого
  прокси до соединения с сервисом. При занятых обычных портах мост выбирает
  свободный порт Windows; старые соединения закрываются при его остановке.
- **Диагностика входа и ошибок.** При сбое синтетического OAuth-запроса сравниваются
  маршруты со Smart DNS и без него. Реальные коды входа не повторяются. Исправлен
  сбой поиска сессии при отсутствующем приложении; журнал UI и обновлятора
  сохраняет очищенную причину ошибки. Частичная подготовка не выглядит полной.
- **Меньше кнопок.** Убраны галочка, дублировавшая «Пропатчить», повторная кнопка
  баг-репорта в журнале и отдельное меню подготовки Antigravity. Подготовка и откат
  собраны в меню выбранного приложения; перед восстановлением есть подтверждение.

Баг-репорты с автоматически приложенным очищенным журналом и необязательной
картинкой, сохранение журнала в выбранный файл и интерактивная консоль CLI
сохранены из 0.2.0. Админка отчётов по-прежнему доступна только через SSH.

## Установка Windows

Закройте прежнюю копию Dagami в трее и распакуйте Windows ZIP в пустую папку.
Внутри один `DagamiAgentProxy.exe`; Python не нужен, требуется .NET Framework 4.8.
Профили и ключ активации остаются в пользовательском хранилище.

Нажмите «Найти приложения». После смены имени/каталога IDE повторите «Пропатчить»
для её ярлыков. Перед сменой маршрута закройте само приложение полностью.
Для общего agy закройте и IDE, и CLI; после изменения CLI-команды откройте терминал заново.

**Откат заменяет ручные правки управляемых proxy-полей исходными значениями.**
Остальные настройки сохраняются. Неизвестные бинарные сигнатуры не изменяются.

## Проверки и ограничения

Проверены Windows-сборка, 123 Python-теста (2 пропуска), 15 нативных наборов,
12 тестов сервиса (1 пропуск), настоящие ярлыки и дочерние процессы на fixtures,
интерактивный cmd, loopback RPC/стриминг, ошибки CONNECT и занятые порты.
Обнаружение MSIX Codex проверено на установленном приложении без его запуска,
остановки или изменения. Исходники и история Git проверены на секреты.
Полный разбор: [RECHECK_20261028.md](RECHECK_20261028.md).

Это альфа. Живой вход и ответы моделей именно в IDE 2.6 пока не подтверждены;
новая структура и транспорт проверены на изолированных стендах. Полные сессии
всех аккаунтов, моделей и версий остальных приложений не проверены. WSL/SSH/remote,
уже работающие daemon и нестандартные пути профилей имеют отдельные ограничения.
Готовых Linux/macOS-бинарников нет: приложены исходники и инструкция сборки.
