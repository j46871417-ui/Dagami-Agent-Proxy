# Dagami Agent Proxy 0.8.0 beta

Тестовая сборка: автоматическое применение проверенного маршрута в Windows и отдельный оплаченный пул по ключу.

- **Автоматическая разблокировка ИИ** при необходимости включает DNS Windows для доменов ИИ и системный PAC. Для DNS появляется UAC. После применения проверяется доступ через Windows; при ошибке изменения откатываются и пробуется другой маршрут. Конфликтующие настройки сохраняются.
- **Приватные прокси по ключу** используют ту же подтверждённую привязку устройства. URL, логины и пароли поставщиков остаются на серверах. Пустой/недоступный приватный пул не заменяется обычным выходом или бесплатным прокси; обычный маршрут тоже не использует приватные прокси неявно.
- **Замер DNS** и диагностика браузеров/порта 53 адаптированы из PR №7. Общий каталог, проверка сертификатов, отбрасывание NXDOMAIN/SERVFAIL/пустых ответов и частных IP, отдельная проверка API. Неизвестный режим браузера не считается системным DNS.
- Исправлена обработка устаревшего входа в закрытую панель оплаченных прокси. Панель позволяет включать, удалять и задавать срок выходов.
- Добавлен проверенный независимый зарубежный вход. Серверы продолжают принимать прежние ключи.

Приложение, свой и публичный прокси работают без ключа. Ключ нужен для обоих серверных режимов Dagami. Приватный пул управляется администратором отдельно от публичных списков.

Для обновления Windows используйте проверку обновлений в приложении с включёнными предварительными версиями. Для ручного обновления завершите Dagami через трей и замените файлы из Windows ZIP в прежней папке. Настройки и привязка находятся отдельно от программы.

В Linux/macOS добавлен выбор оплаченного профиля. Автоматическая запись системных DNS/PAC в этом обновлении относится к Windows. Linux/macOS проверяются кросс-компиляцией; отдельный тест на реальной ОС обязателен перед массовым распространением. Сборки без цифровой подписи и нотаризации.

Сетевые проверки без аккаунта не гарантируют ответ модели для каждого аккаунта. Android остаётся прототипом в исходниках.
