# Dagami Agent Proxy 0.2.0 альфа

Обновление после `v0.1.0-alpha.10`. Это предварительный выпуск; доступ аккаунтов
к моделям и поведение всех версий поддерживаемых приложений не подтверждены.

## Изменения

- Восстановление/поиск удалённых и перемещённых ярлыков, writable-копии общих
  ярлыков, проверки коллизий и возврат всех изменений при частичной ошибке.
- Подготовка совместимых Antigravity IDE/Manager и agy CLI с проверкой бинарных
  сигнатур, резервными копиями и откатом. Неизвестные бинарники не изменяются.
- Исправлен запуск интерактивных CLI: команда использует console EXE, cmd ждёт
  завершения и не конкурирует с дочерней программой за ввод.
- Отдельные политики IDE семейства VS Code, Codex/OpenCode Desktop и CLI,
  Gemini CLI, Claude Code, Git (`dagami-git`) и JetBrains. Настройка npm-обёрток
  без shell=True и без добавления несуществующих proxy-полей в TOML/JSON.
- PowerShell/pwsh/cmd больше не добавляются автоматически. Ручное добавление
  терминала и управление ранее сохранёнными настройками остаются доступны.
- Баг-репорты в Windows: автоматически приложенный очищенный журнал, PNG/JPEG
  с предпросмотром, зашифрованная очередь и повтор без дубликатов. Сервис сайта
  принимает отчёты; закрытая панель показывает журнал, картинку и статусы.
- Исправлены обработка повреждённых журналов, пути portable/JetBrains-профилей,
  восстановление отсутствующих конфигов и сохранение данных при неудачном откате.
- Кнопка «Баг-репорт» доступна с любого экрана. В «Журнале» кнопка
  «Сохранить в файл…» открывает выбор папки и имени файла; журнал сохраняется
  в UTF-8 с очисткой секретов и подтверждением замены существующего файла.
- Админка сайта и её API закрыты снаружи; просмотр отчётов доступен только
  через SSH-туннель с авторизацией. Публичная отправка отчётов остаётся доступна.
- Нативные исходники и ресурсы перенесены в `src/`, сборочные скрипты — в `tools/`.
  Обновлены упаковка, проверки и инструкции; добавлены `AGENTS.md` и `.agents/`.

## Установка

Закройте прежний Dagami в трее и распакуйте Windows ZIP в пустую папку. Аккаунт,
профили и ключ активации остаются в пользовательском хранилище. Для ранее созданной
команды agy повторите «Пропатчить» в новой версии и откройте терминал заново.

Откат **заменяет ручные правки управляемых proxy-полей исходными значениями**.
Остальные настройки сохраняются. Перед изменением приложения закройте его целиком.

## Проверки и границы

Проверены Windows-сборка, регрессионные сценарии, реальные ярлыки/дочерние процессы,
интерактивный cmd и передача трафика через loopback. Сервис проверен на Linux,
форма/админка — в браузере; HTTPS-отправка журнала/картинки — из Windows EXE.

Полные рабочие сессии со входом в аккаунты, всеми моделями и стримингом не проверены.
Удалённые окружения, WSL/SSH, уже запущенные daemon и приложения, игнорирующие proxy
env, имеют отдельный сетевой контекст. Изменение путей профиля между версиями IDE
может потребовать ручного восстановления. Готовых Linux/macOS-бинарников нет.
Подробности: [MATRIX.md](MATRIX.md), [BUG_REPORTS.md](BUG_REPORTS.md).
