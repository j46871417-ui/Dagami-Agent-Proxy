# Dagami Agent Proxy 0.7.2 beta

В Windows исправлена ошибка SSL/TLS при вводе ключа и проверке привязки.
При сбое до отправки запроса приложение может обратиться к резервному входу.
Текущие ключи и настройки сохраняются.

## Изменения 0.7.1 beta

- Приложение запускается без активации. Ключ из `/key` нужен для прокси Dagami.
- В Windows «Применить» сохраняет параметры, «Включить прокси Windows»
  запускает выбранный маршрут. Поддерживаются свой прокси, публичный адрес и
  Dagami по ключу. Для своего адреса добавлены SOCKS4/4a и SOCKS5 поверх TLS.
- Gemini Desktop поддерживает патч и откат ярлыков Gemini и его лаунчера.
- В Windows исправлено зависание двустороннего туннеля Smart DNS. В меню
  доступно восстановление подключения. Обновлённое расширение возвращает
  прежние настройки браузера при недоступном маршруте.
- Для Linux и macOS подготовлены сборки x64 и ARM64. HTTP/2 CONNECT доступен
  в Go-клиенте для отдельно настроенного шлюза. Android доступен в исходниках
  как прототип диагностики.

## Обновление с 0.7.0 и 0.7.1 beta

Откройте «Обновления», разрешите поиск предварительных версий и выберите
0.7.2 beta. Windows-обновление сохраняет настройки и привязку прокси.
Встроенный обновлятор 0.7.0 заменяет основной EXE. Отдельные
`DagamiRecovery.exe` и `DagamiUninstall.exe` доступны в полном Windows ZIP.
Восстановление можно запустить и из меню обновлённого приложения.
Если приложение запущено от администратора или лежит в защищённом каталоге,
используйте ZIP для ручного обновления.

Windows-сборка без Authenticode-подписи. HTTP/2 требует включения на шлюзе.
Android APK пока отсутствует.
