# Dagami Agent Proxy 0.7.4 beta

- В новых профилях Windows выбран MagicDNS с DoH-адресом `https://api.magicinfo.art/rpc`. При обновлении сохраняется выбранный DNS. DNS для приложений и служба Windows включаются вручную.
- Экран **DNS** показывает ответы по каждому проверенному узлу. Выбор для запуска через Dagami и включение DNS в Windows доступны отдельными кнопками. **Где сохраняется…** показывает пути к настройкам, каталогу, журналу и резервной копии.
- Приложение обновляет каталог по данным известных провайдеров и проверяет новые адреса. При сбое обновления сохраняется последний рабочий список.
- Для Antigravity виден DNS, выбранный для запроса к API модели, включая переход на резерв. Результаты DNS и работы модели отображаются отдельно.

## Обновление

В Windows откройте **Обновления**, разрешите предварительные версии и установите 0.7.4 beta. Обновление по прежнему пути сохраняет настройки и привязку прокси. Если Dagami установлен в защищённый каталог или запущен от администратора, полностью закройте его и распакуйте Windows ZIP в прежнюю папку.

Для Linux и macOS доступны архивы x64 и ARM64. Чтобы обновиться, закройте Dagami и замените приложение из архива для вашей архитектуры, сохранив прежний путь установки. Профили хранятся отдельно от файлов программы.

Windows-сборка без Authenticode-подписи. Android доступен в исходном архиве как прототип диагностики.
