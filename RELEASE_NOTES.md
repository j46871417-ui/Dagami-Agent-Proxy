# Dagami Agent Proxy 0.7.3 beta

- В Windows карточка Antigravity показывает ожидание запроса, начало ответа модели или региональный отказ Google.
- Действие **Другой маршрут** проверяет доступные альтернативы. Если два профиля Smart DNS используют тот же адрес ретранслятора, на котором недавно получен отказ, Dagami пропускает оба. В журнале видны результаты проверки сети и исход запроса модели.
- Диагностика Antigravity проверяет вход Google, обмен кода и потоковый API. Сетевая проверка выполняется без входа в аккаунт. Ответ модели нужно проверить в Antigravity.

## Обновление

В Windows откройте **Обновления**, разрешите предварительные версии и установите 0.7.3 beta. Обновление по прежнему пути сохраняет настройки и привязку прокси. Если Dagami установлен в защищённый каталог или запущен от администратора, полностью закройте его и распакуйте Windows ZIP в прежнюю папку.

Для Linux и macOS доступны архивы x64 и ARM64. Чтобы обновиться, закройте Dagami и замените приложение из архива для вашей архитектуры, сохранив прежний путь установки. Профили хранятся отдельно от файлов программы.

Windows-сборка без Authenticode-подписи. Android доступен в исходном архиве как прототип диагностики.
