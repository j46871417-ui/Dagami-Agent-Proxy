# Dagami Agent Proxy 0.5.0 beta

## Подключение

- Получите ключ `DAGAMI1-…` через `/key` в [@bright26bot](https://t.me/bright26bot) и вставьте его в Dagami. Приложение определит адрес шлюза и привяжет устройство.
- В Windows свой HTTP/HTTPS-прокси можно ввести прямо на вкладке «Подключение». Поддерживаются адреса вида `host:port`, URL с реквизитами и `direct` для системного VPN. Ручной адрес хранится отдельно от маршрута Dagami.
- В macOS и Linux свой HTTP-, HTTPS- или SOCKS5-прокси добавляется через «Подключение → Свой прокси».
- Активный маршрут получают совместимые приложения, запущенные из Dagami. На Windows он также используется настроенными ярлыками и командами CLI.

## Windows

- В списке вернулись значки установленных приложений. Они загружаются в фоне при поиске приложений.
- В Windows-архиве находятся EXE и его контрольная сумма для встроенного обновлятора.
- Для ручного обновления завершите прежний Dagami через «Выход» в трее. Сохраните новый EXE по прежнему пути, чтобы ярлыки запускали его.

## Пакеты

- Windows x64 и отдельный `DagamiAgentProxy.exe`.
- macOS для Apple Silicon и Intel, Linux для x64 и ARM64.
- Исходники, `SHA256SUMS.txt` и `SHA256SUMS.json`.

Выполнены локальные проверки Windows и кросс-сборка macOS и Linux. Пакеты подготовлены без Authenticode и нотаризации macOS.
