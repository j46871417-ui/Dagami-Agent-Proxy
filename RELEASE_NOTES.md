# Dagami Agent Proxy 0.8.1 beta

- **Каталог DNS.** В разделе «DNS и сброс» можно обновить общий список DoH и DoT и выбрать провайдера с проверенными адресами.
- **Перебор публичных прокси в Windows.** Видно, сколько адресов в списке, сколько проверено, сколько ответили, сколько подходят и сколько остались без ответа. Каждый проверенный адрес получает номер и результат, например тайм-аут или отказ CONNECT. После подключения отображается номер используемого прокси.
- **Повторный поиск.** Dagami проверяет до 12 адресов за раз и при повторном запуске переходит к следующей группе. Если проверенный вариант не применился в Windows, автоматический подбор пробует оставшиеся варианты.
- **Antigravity.** После подтверждённого регионального отказа виден прогресс проверки настроенных резервных маршрутов. Найденный маршрут можно применить из карточки приложения. Результат запроса модели проверяется в Antigravity.
- **Приватный пул.** Windows восстанавливает выбранный приватный профиль по ключу при повторном запуске.

Для обновления Windows включите предварительные версии в настройках обновлений. Для установки из ZIP полностью завершите Dagami через трей и замените файлы в папке приложения. Настройки и ключ прокси хранятся отдельно.

Счётчики публичных прокси и фоновый поиск Antigravity добавлены в клиент Windows. В сборках Linux и macOS обновлён номер версии.
