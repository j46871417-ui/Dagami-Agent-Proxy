# Маршрутизация приложений в Dagami

## Как выбрать маршрут

По умолчанию Dagami использует управляемый маршрут. Откройте «Подключение»
и подтвердите устройство через Telegram. Запуск из Dagami и настроенные ярлыки
используют выбранное подключение. См. [MANAGED_ACCESS.md](MANAGED_ACCESS.md).

Для собственного прокси в Windows откройте «Подключение», введите адрес
HTTP/HTTPS и нажмите «Использовать свой прокси». Для VPN/TUN укажите `direct`. Переносимый
клиент также поддерживает собственные профили SOCKS5 и явный выбор системного
маршрута. Например, `socks5://127.0.0.1:7897` подходит, если VPN-клиент слушает
SOCKS5 на этом порту.

Откройте «Приложения», при необходимости укажите путь к исполняемому файлу и
запустите его из Dagami. Полностью закройте предыдущую сессию клиента, включая
процесс в трее. Клиент с одним экземпляром может передать управление уже
запущенному процессу с прежними сетевыми настройками. В переносимой сборке
действие «Запустить» для CLI покажет команду терминала.

Dagami поднимает HTTP-прокси на `127.0.0.1` и передаёт его адрес
запускаемому процессу через `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY` и их
аналоги в нижнем регистре. `NO_PROXY` включает loopback для локального OAuth.
Для Chromium и обнаруженных Electron-клиентов также передаётся `--proxy-server`. HTTPS
идёт по CONNECT с сохранением TLS между клиентом и сервисом. Для сетевого
клиента, который игнорирует proxy env или флаги, используйте сетевые настройки
самого клиента, системный маршрут с VPN/TUN или браузерную версию.

## Как отличить проблемы маршрута от отказа сервиса

1. В разделе «Подключение» выберите сервис для проверки. Dagami запрашивает
   фиксированные публичные адреса без аккаунта, переходов по редиректам и
   запросов к модели. Сравните ошибки TLS и HTTP-коды на разных маршрутах.
2. Запустите приложение через выбранный профиль и проверьте его встроенную
   диагностику, авторизацию и потоковый ответ. HTTP 401/403 в проверке Dagami
   означает, что сервер ответил. Причину отказа показывает сам клиент.
3. Географические ограничения на уровне подключения могут зависеть от IP
   выхода. Допуск аккаунта, регион магазина, разрешения организации, квота и
   политика сервиса проверяются отдельно. Смотрите правила поставщика для
   своего аккаунта и сервиса. [Доступность ChatGPT](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries), [доступность Claude](https://www.anthropic.com/supported-countries)

## Сборка с меньшей поверхностью для ложных срабатываний

`Dagami-Routing-<система>-<архитектура>.zip` содержит маршрутизацию, профили,
сессии и диагностику. В нём исключены управление DNS/NRPT, повышение прав для
этих операций и анализ бинарников. Routing использует системные окна Win32,
AppKit и GTK 3. Полная сборка Windows с патчами Antigravity использует WinForms.

```text
go run ./cmd/dagami-build -target all -routing-only -test -out dist-portable/routing
```

Для релиза Windows используйте сертификат подписи кода издателя в хранилище
текущего пользователя и SignTool из Windows SDK. Добавьте к команде
`-sign-tool <путь к SignTool.exe> -sign-thumbprint <отпечаток сертификата> -timestamp-url <HTTPS RFC 3161 URL>`.
Сборщик подпишет EXE с SHA-256, проверит подпись и затем сформирует архивы и
`SHA256SUMS.json`. Для полной сборки те же флаги поддерживают и WinForms EXE.

SmartScreen учитывает репутацию издателя и файла. Детекты Defender и других
антивирусов нужно измерять отдельно на готовом релизе. Для подтверждённого
ложного срабатывания укажите в обращении поставщику антивируса имя детекта,
версию и SHA-256 релизного файла. [SignTool](https://learn.microsoft.com/en-us/windows/win32/seccrypto/signtool), [репутация SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation), [разбор ложных срабатываний Defender](https://learn.microsoft.com/en-us/defender-xdr/developer-faq)

В текущем окружении сборки выпущены без подписи. Тесты подтверждают работу
прокси-моста на локальных стендах, выбор параметров запуска и пакетирование.
Вход, доступ аккаунтов к моделям и показатели срабатываний антивирусов на этих
артефактах не измерялись.
