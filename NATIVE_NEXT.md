# Dagami Agent Proxy: Go/Rust и прямое меню

Ветка `refactor/native-core-flat-ui`, обзор источников 7 ноября 2026.

## Какую сборку открыть

- **Профили, запуск через прокси и проверка связи:** `Dagami-Routing-<система>-<архитектура>.zip`.
  Сценарии для приложений и выпуск Windows-пакета описаны в [APP_ROUTING.md](APP_ROUTING.md).
- **Windows, привычный интерфейс и все существующие функции:** `windows-native/DagamiAgentProxy.exe`.
  У него прямые разделы «Приложения», «Подключение», «DNS и сброс», «Журнал» и
  «Диагностика». Ручной DNS и сброс NRPT находятся на странице DNS.
- **Общий переносимый клиент:** `Dagami-Portable-<система>-<архитектура>.zip`.
  Он запускает локальное окно в браузере, один процесс на Go с вшитым Rust-модулем.
  Сервер UI слушает `127.0.0.1` на случайном порту и требует ключ текущего запуска.
  Подходит для проверки нового клиента; пока не замена нативной Windows-версии
  для автоматических патчей Antigravity и шифрованной системной службы DNS.

Ни в одном из этих пакетов нет Python. Настройки прежней версии не переносятся
автоматически: у Go-клиента отдельный каталог `DagamiAgentProxy/native-v1` в
пользовательских настройках ОС. Windows защищает реквизиты через DPAPI,
macOS — через Keychain, Linux — через Secret Service (`secret-tool`).
Пароль не передаётся через аргументы процесса. Если хранилище недоступно,
сохранение защищённого профиля завершается ошибкой.

Пакеты macOS и Linux собраны кросс-компиляцией. Нужен локальный браузер;
на Linux для работы с системным DNS нужны systemd-resolved и polkit.
macOS-пакет не подписан сертификатом Developer ID. Реальные запуски и запись DNS
на этих ОС в рамках этой ветки не подтверждены. Настройку DNS проверяйте на
тестовой машине, особенно при VPN, DHCP и нескольких сетевых службах.

## Что перенесено

| Возможность | Новый клиент Go/Rust |
| --- | --- |
| Профили, выбор, удаление, хранение реквизитов | Go + хранилище ОС |
| Запуск графических приложений, CLI в текущем терминале, proxy env и Chromium flags | Go |
| HTTP/HTTPS/SOCKS5 мост, ограничение соединений, TLS, повтор CONNECT до передачи данных | Go |
| Проверка TLS и ответов серверов | Go; без запросов к модели |
| Сессии, журнал, сохранение отчёта | Go; журнал в памяти текущего запуска |
| Ручной DNS и восстановление | Адаптеры ОС; Windows использует прежний PowerShell-движок |
| Полный сброс DNS и NRPT | Windows, два подтверждения; сохраняется резервная копия |
| Поиск backend IDE, сигнатуры и SHA-256 | Go + встроенный Rust; диагностика без записи |
| Сборка, пакетирование, выборочные Windows-проверки | Go + Cargo |

Старый Python-код оставлен в репозитории для сопоставления функций и отката.
Он не включается в новый архив исходников и не вызывается новым сборщиком.
Совместимость автоматических ярлыков и патчей всех версий, автозапуск/трей и
перенос старых профилей в Go-клиенте не достигли паритета. Нативный Windows EXE
остаётся вариантом для этих функций. Отдельный сервер баг-репортов не входит в
настольные пакеты и в этой ветке не мигрировал.

## Сборка без Python

Понадобятся Go 1.23+, Rust/Cargo с целью `wasm32-unknown-unknown`, на Windows
для сборки WinForms — .NET Framework 4.x. В корне проекта:

```text
rustup target add wasm32-unknown-unknown
go run ./cmd/dagami-build -target all -test -source
```

На Windows добавьте `-windows-native -native-checks`. Результат в
`dist-portable/native-next`, с `SHA256SUMS.json`. Один исполняемый файл на пакет;
Rust-модуль и HTML/CSS/JS встраиваются при сборке. Для браузерного превью без
записи настроек: `DagamiAgentProxy -preview`. `inspect-binary PATH` печатает
отчёт по файлу без записи. Он не подтверждает, что файл безопасно патчить.
`DagamiAgentProxy run codex -- --help` запускает зарегистрированный CLI через
активный профиль с обычным stdin/stdout.

## Что взяли из источников

- [Dagami mac.28](https://github.com/ImRealDerli/Dagami-Agent-Proxy-macOS/releases/tag/v0.4.1-mac.28-beta): ограниченный транспорт, двухсторонняя передача,
  сохранение TLS и один повтор CONNECT до передачи данных. В интерфейсе —
  компактные карточки и отдельные профили с понятным состоянием.
- [confeden 2.28.2](https://github.com/confeden/Antigravity/releases/tag/v2.28.2):
  явно показывать состояние backend и учитывать внешний `.gemini/bin/agy`.
  Успешная проверка маршрута не выдаётся за ответ модели. Пулы чужих прокси
  и код проекта не включены.
- [Open AG Patcher](https://github.com/trustybird/AvenCores-open-antigravity-patcher):
  отличать локальный патч от серверного отказа. Код GPL не заимствован.

Переключения в DNS и патчи на живых приложениях при проверке не запускались.
Производительность реальной модели и выходов VPN зависит от сети; результаты
loopback-тестов не подтверждают скорость или доступность аккаунта.
