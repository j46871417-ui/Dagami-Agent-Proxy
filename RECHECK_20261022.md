# Проверка доработок перед 0.2.0 альфа

Проверен текущий checkout относительно `v0.1.0-alpha.10`: ярлыки, бинарная
подготовка Antigravity/agy, расширение приложений, запуск, конфигурация и откат.
Этот отчёт фиксирует проход до подготовки выпуска. Позднее добавлены баг-репорты,
исправление консоли и HTTPS; система сайта развёрнута с разрешения владельца.
Актуальный состав выпуска: [RELEASE_NOTES.md](RELEASE_NOTES.md).

## Выявлено и исправлено

До исправлений новые тесты воспроизвели пять ошибок Windows и шесть
ошибок/подсценариев Python. Затем проверены остальные обнаруженные случаи.

| Приоритет | Проблема | Исправление |
|---|---|---|
| P1 | Первый ярлык уже восстанавливался, когда следующий оказывался изменён извне | Предварительная проверка всей операции; компенсация файлов и журнала при сбое записи |
| P1 | Настройки IDE и копия менялись раньше, чем откат запускателя завершался ошибкой | При ошибке запускателя конфиг и копия возвращаются к состоянию перед попыткой |
| P1 | Повреждённый Python state.json трактовался как пустой и мог быть перезаписан | Повреждённый JSON/неверная структура останавливают изменение; исходный файл сохраняется |
| P1 | Python сообщал об успешном восстановлении и стирал журнал после ошибки | Возвращается False; незавершённые записи сохраняются для повторной попытки |
| P1 | Неверные метаданные JetBrains позволяли записать закешированный старый конфиг | Запись останавливается; прежний путь автоматически не используется |
| P2 | В неподдержанный Desktop-конфиг могли записаться VS Code proxy-ключи | Для известных Desktop/CLI типов такая запись запрещена |
| P2 | Удалённый portable data оставался целью записи | Путь конфигурации пересчитывается |
| P2 | Удалённый settings.json не восстанавливался из копии; XML терял другие компоненты | Восстановление без текущего файла сохраняет исходные посторонние параметры |
| P2 | Удаление исходного CLI лишало его запускающую команду корректного статуса/отката | Учитывается журнал; исчезнувшие зарегистрированные приложения остаются в списке |
| P2 | Удалённый собственный CLI-запускатель нельзя было повторно создать | Повторный патч восстанавливает отсутствующий запускатель; чужие изменения существующего защищены |
| P2 | GUI с тем же именем скрывал CLI в PATH; Python выбирал произвольный старый Codex | Различаются console/GUI; нативный поиск продолжает PATH, запасной Codex-поиск сортируется по времени |
| P2 | Python запускал npm CMD напрямую; entrypoint без расширения не распознавался | Стандартные обёртки запускаются через Node без shell, поддержаны JS/MJS/CJS и файлы без расширения; выход из каталога установки запрещён |
| P2 | Один недоступный для записи ярлык срывал настройку | Он пропускается; при необходимости создаётся доступная пользовательская копия с исходными метаданными, результат сообщает о пропуске |
| P2 | Допустимый путь становился слишком длинным из-за суффикса временного файла | Короткие самостоятельные временные имена; проверен ярлык с путём около 249 символов |
| P2 | Имя приложения NUL и другие DOS-имена ломали создание ярлыка | Добавлен безопасный префикс |
| P2 | При расширении набора Python-ключей не записывались исходные значения новых | Журнал дополняется, исходная база уже управляемых ключей сохраняется |
| P2 | Старый откат Codex терял пустой/удалённый корневой proxy и затрагивал профили | Возвращается корневой ключ, включая пустую строку; секции профилей сохраняются |
| P2 | Ошибка Windows Job молча разрешала Python-запуск без Job; частичный IPC оставлял ресурсы | При ошибке Job новый запуск не выполняется, мост закрывается; неудачный IPC очищается |
| P3 | Повреждённый CLI-журнал мог нарушить классификацию GUI | Ошибка обрабатывается без перезаписи журнала; другие GUI продолжают определяться |
| P3 | Длинный результат обрезался; Git назывался обычной командой; ограничения обещали лишнее | Полный результат доступен в подсказке, интерфейс называет dagami-git; убраны обещания гарантированного охвата sandbox и отсутствия обрывов |

Основные файлы: NativeShortcuts.cs, NativeSessions.cs, NativeCliApps.cs,
ApplicationSupport.cs, ApplicationDiscovery.cs, JetBrainsProxySettings.cs,
DevProxyApp.cs; Python launcher/recovery/adapters.

Откат proxy-полей **по-прежнему заменяет ручные изменения** исходными значениями.
Это согласованное поведение. Остальные параметры сохраняются.

  ShortcutChecks: 29; ShortcutRecoveryChecks: 15; NativeLoginChecks: 24;
  GoogleGeminiChecks: 29; AntigravityPatchChecks: 21; LocalUiChecks: 116.
- Симуляция преобразования реальной резервной копии Antigravity в памяти:
  171416064 байта, 10 изменений; размер сохранён, исходный файл не менялся.
- Нативная сборка успешна. Проверена геометрия обычного/минимального окна,
  PNG основного окна просмотрен. git diff --check без замечаний.
- Source hygiene для индекса прошёл. Это не проверка всех незакоммиченных новых
  файлов и не выдаётся за полную проверку рабочей копии.

LicenseChecks не запускался: он меняет настоящую активацию. Проверки установки

не менялись, вмешательство в установку и сетевые настройки не требовалось.

## Оставшиеся ограничения и доработки

1. **Живые приложения и аккаунты.** Структурные тесты не подтверждают вход,
   запрос модели и стриминг во всех версиях. Нужны проверки на установленных
   версиях с рабочими аккаунтами. Недостающие программы здесь не устанавливались.
2. **Смена каталога настроек после обновления IDE.** Копии привязаны к пути.
   Автоматический обход и откат всех старых версий/профилей, особенно JetBrains,
   пока не реализованы. Нестандартный idea.config.path тоже требует отдельной
   настройки. Сохранённые копии не удалялись.
3. **Быстрый Windows launcher и Job.** Нативный Process.Start выполняется до
   присоединения к Job: очень быстрый launcher может породить ребёнка раньше.
   Некоторые native-пути допускают продолжение при неудаче привязки, записывая
   предупреждение. Для строгой гарантии нужен suspended-start и Job до resume.
   Нынешние тесты обычного наследования эту гонку полностью не закрывают.
4. **Разные сетевые контексты.** WSL, контейнер, remote extension host, старый
   build daemon, SSH и программа, игнорирующая proxy env, универсально не
   перенастраиваются. Для остальных продуктов применяются штатные настройки
   и запуск; подтверждённое бинарное преобразование относится к Antigravity/agy.
5. **История бинарных копий без квоты.** После многих обновлений крупные backend
   могут занять заметное место. Нужны отображение объёма и явная политика очистки.
6. **Одновременные Python-записи состояния.** Атомарная замена защищает файл от
   половинчатой записи, но load→change→save пока не имеет общей межпроцессной
   блокировки для всех вызывающих функций. Это не объявляется исправленным.
7. **Закрытые MSIX-поставки.** Поиск Desktop использует известные пути, App Paths
   и доступный EXE работающего процесса. Полного перечисления закрытых MSIX
   нет; иногда нужен ручной выбор.
8. **Формат JSONC в C#.** Значения посторонних ключей сохраняются, комментарии
   и форматирование при сериализации не сохраняются. Python-редактор работает
   иначе; для C# нужен редактор точечных изменений.

Это реальные оставшиеся ограничения/доработки, а не провал новых тестов.
Все выбранные проверки после исправлений прошли. Они не заменяют проверку
всех сторонних приложений и сетевых режимов.

Актуальная сборка: ../dagami-recheck-local/windows/DagamiAgentProxy.exe.
Предыдущие архивы сохранены. Сайт не менялся, баг-репорты остаются отдельным
[планом](BUG_REPORTS_PLAN.md).
