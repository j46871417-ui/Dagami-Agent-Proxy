# Windows CLI: настройка обычной команды — cli4, 16 октября 2026

## Причина

В alpha.2/fix2 «Пропатчить» работало с обычными .lnk. Для agy.exe на скриншоте
ярлыков не было; настройка отклонялась с предложением создать ярлык. Это не настраивало
обычную команду agy в терминале. Windows CLI обнаружение также ограничивалось Codex
из каталога OpenAI и не охватывало типичные npm CMD/PS1.

## Реализация

- Консольный EXE определяется по PE subsystem; CMD/BAT/PS1 считаются CLI-обёртками.
- Для CLI кнопка «Пропатчить» устанавливает отдельный EXE-запускатель команды в
  `%LOCALAPPDATA%\DagamiAgentProxy\cli\bin`. Исходный EXE/скрипт не заменяется.
  Используется `dagami-proxy.exe` из того же архива и с той же FileVersion, что GUI.
- В пользовательский PATH добавляется только каталог запускателей. Нужен полный
  перезапуск терминала/Windows Terminal/IDE-терминала: работающий родительский
  процесс не получает новое окружение автоматически. Машинный PATH не меняется.
- Журнал оригинальных путей и контрольных сумм защищён DPAPI CurrentUser. Паролей
  прокси в запускателях/журнале нет; подключение читается из защищённого профиля.
- Запускатель поднимает отдельный loopback-мост на свободном порту на время CLI,
  передаёт HTTP_PROXY/HTTPS_PROXY/ALL_PROXY, исключения loopback, AGY_PROXY_URL,
  AG_LS_PROXY и NODE_USE_ENV_PROXY=1 только дочернему процессу. TLS не отключается.
  [Прокси в Node.js](https://nodejs.org/learn/http/enterprise-network-configuration)
  и [сетевые настройки OpenCode](https://dev.opencode.ai/v2/docs/network/).
- Сохраняются аргументы, stdin/stdout/stderr, текущий каталог и код завершения.
  CLI-запуск не проходит через GUI-брокер, который не сохранял терминальную сессию.
  Ctrl+C остаётся событием общей консоли; автоматическое повторение запросов не добавлялось.
- Стандартные npm CMD/PS1 распознаются и запускают Node entrypoint напрямую без
  CMD-разбора пользовательских аргументов. Неизвестная CMD/BAT отклоняется до изменений.
  Обычные PS1 запускаются через PowerShell -File без обхода ExecutionPolicy.
- Автопоиск использует PATH для Codex, agy, OpenCode, Gemini CLI, Claude Code.
  Собственные запускатели исключены из поиска, поэтому повторная настройка не зацикливается.
- GUI показывает «Запускать обычную команду через прокси». Отключение удаляет
  только собственный неизменённый запускатель и принадлежащую Dagami запись PATH.
  Изменения других программ в PATH сохраняются. При чужом изменении EXE откат останавливается.
- Установка транзакционна: при ошибке записи PATH возвращаются запускатель и журнал.
  Системные команды node/python/git/cmd/powershell не подменяются. Если одноимённая
  команда уже есть в машинном PATH, настройка отклоняется с объяснением приоритета.

## Использование

GUI: «Пропатчить» → полностью перезапустить терминал → обычная команда `agy`.
CLI: `dagami-proxy apps`, `dagami-proxy patch APP_ID`, `dagami-proxy unpatch APP_ID`.
Один запуск без изменения PATH: `dagami-proxy run APP_ID -- ARGS`.
Пример для найденного Codex: `dagami-proxy run codex -- --version`.

Для обновления завершите прежний менеджер через «Выход» в трее. Сохраните оба старых
EXE и замените `DagamiAgentProxy.exe` и `dagami-proxy.exe` по прежнему пути файлами
из одного архива. Аккаунты/профили не удаляйте. В GUI должна быть версия cli4.
Для CLI без ярлыков нажмите «Пропатчить», не «Создать ярлык».

## Проверки и ограничения

Пройдены 37 CLI-проверок (откат/конфликты PATH, npm, аргументы с пробелами, пустая
строка, кавычки, обратные слэши, метасимволы и Unicode, stdin/stdout/stderr, код 37,
cwd и реальные байты через тестовый upstream). Ещё 31 проверка обычных GUI-ярлыков,
30 userinfo, 33 EOF/no replay, 24 входа/relay, 29 Google/Gemini, 204 UI. Всего 388.

Отдельный временный agy.exe запущен обычной командой из CMD и PowerShell через
установленный EXE-запускатель. Подтверждены bootstrap, аргументы, stdin/stdout/stderr,
код 37, неизменность исходного файла. Для тестов PATH был подменён тестовым объектом;
реальные настройки пользователя не менялись. Существующие активация и профиль только
читались. Реальный установленный Codex выполнил `--version` через новый runner.
Это не проверка его аккаунта/ответа модели и не тест конкретного agy пользователя.

Явный путь к исходному EXE, PowerShell alias/function и команда из текущего каталога
могут обходить PATH-запускатель. Старые терминалы и уже работающие фоновые службы
нужно перезапустить. Долгоживущий сторонний сервис, ранее запущенный вне Dagami,
не перенастраивается. Приложение должно поддерживать переданные proxy-переменные;
этот механизм не перехватывает произвольные сокеты. Старые Node без env-proxy
не получают эту возможность от одного NODE_USE_ENV_PROXY.

Диагностика userinfo из diag3 сохранена. HTTP 502 у пострадавших пользователей
не объявляется исправленным: нужен отчёт с проблемного ПК.
Проверки CLI первоначально выполнены на FileVersion 0.1.0.4 / cli4.
