# Dagami Agent Proxy

Менеджер запуска IDE и CLI через свой прокси. Профили, запуск приложений,
ярлыки, системный DNS с копией и откатом. Ранее — DevProxy.

**[Скачать v0.1.0-alpha.10](https://github.com/j46871417-ui/Dagami-Agent-Proxy/releases/tag/v0.1.0-alpha.10)**
· **[Собрать Linux / macOS](BUILD_LINUX_MACOS.md)**

## Что есть в выпуске

| ОС | Что доступно | Статус |
|---|---|---|
| Windows | ZIP с одним `DagamiAgentProxy.exe` | Сборка и локальные тесты выполнены |
| Linux | Код, GUI/CLI, сессии, DNS NM, автозапуск и план сборки | Готового бинарника нет; нужны пробы на Linux |
| macOS | Код, GUI/CLI, сессии, DNS, автозапуск и план сборки | Готового `.app` нет; нужны пробы и подпись на Mac |

Файлы `dagami-proxy.exe` и `DagamiDns.exe` больше не нужны. Один главный
файл служит для GUI, CLI, окна DNS и запроса прав. Ключи и готовые файлы
сборок не хранятся в Git. [Правила исходников](SOURCE_POLICY.md).

## Windows: запуск и смена версии

1. Скачайте Windows ZIP из выпуска. Python для него не нужен; нужен
   .NET Framework 4.8, штатный для новых Windows 10/11.
2. Закройте прежнюю копию в трее. Распакуйте новый ZIP **в пустую папку**.
3. Запустите `DagamiAgentProxy.exe` и подтвердите права ОС.
4. Выберите профиль и приложение. Перед сменой маршрута полностью
   закройте само приложение; уже открытый процесс не получит новое окружение.

Прежние профили и ключ активации остаются в хранилище пользователя.
Ключ берётся в [@bright26bot](https://t.me/bright26bot?start=dagami).
Обычная команда CLI также идёт через один файл:

```powershell
.\DagamiAgentProxy.exe --help
.\DagamiAgentProxy.exe --dns-window
```

В «Подключение» можно включить вход в Windows с запуском в трей и правами
админа. Пароль учётной записи не сохраняется. [Автозапуск](STARTUP.md).
Кнопка «Пропатчить» для CLI задаёт обычную команду в PATH пользователя.
После смены команды полностью откройте терминал заново.

## DNS и сеть

По умолчанию Smart DNS задаёт лишь правила доменов. Общий DNS сети
меняется отдельным пунктом с выбором нужных подключений.
До и после записи есть пробы DNS и HTTPS. Ошибка вызывает откат;
отчёт отдельно укажет, если доступ к сети после отката не подтверждён.
Чужие правки сохраняются, удалённые подключения пропускаются.

Красная кнопка полного сброса охватывает и чужие DNS/NRPT в Windows.
Она задаёт два вопроса «Вы точно уверены в том что вы делаете?».
До записи хранится копия. Сброс может лишить сеть рабочих имён;
он не служит пробой сборки. [Режимы DNS и возврат](SYSTEM_DNS.md).

## Linux и macOS: сборка самим пользователем

Скачайте архив исходников из того же выпуска либо клонируйте тег.
Собирать нужно на самой ОС и её архитектуре, от обычного пользователя.

**[Полный план с командами для Linux и macOS](BUILD_LINUX_MACOS.md)**

На Linux результат — один `dagami-agent-proxy`, на macOS — один
`Dagami Agent Proxy.app` с главным файлом и ресурсами внутри. GUI и CLI
используют тот же файл. Права для DNS запрашиваются отдельно.

Linux: общий DNS через NetworkManager; домены требуют уже включённый
dnsmasq. macOS: службы networksetup и файлы resolver. Свои службы VPN
и иной менеджер DNS могут быть вне этих путей. Эти режимы ещё не прошли
наши живые пробы на целевых ОС. Windows-обновлятор и окно активации
пока не перенесены. [Методы, копии и пределы](PORTABLE.md).

## Приложения и пароли

Есть адаптеры Antigravity, VS Code, Cursor, Windsurf, VSCodium,
OpenCode, Codex CLI и Codex Desktop. Поддержка конкретной версии,
вход в аккаунт и доступ к моделям проверяются в самом приложении.
Неизвестный бинарный патч не применяется; у прокси и ярлыков свой путь.

Пароли хранятся в средствах ОС. Если Secret Service или Keychain закрыт,
сохранение пароля в открытый файл не допускается. Логи ограничены
по размеру; вывод приложений с токенами не пишется в журнал сессии.

Сборки: `python build_native_app.py` на Windows;
`python build_portable.py` на Linux/macOS после установки зависимостей.
Скрипты сами не загружают и не публикуют файлы.
